# 喬太守亂點鴛鴦譜

重溫 DOS／ETBASIC 年代輸入男女姓名、看看適合度的小遊戲。找不到記憶中的程式，於是借助 AI 自製一個網頁致敬版；不是原版復刻，也不宣稱使用原作演算法。

**[立即遊玩](https://eric2100.github.io/qiao-matchmaker/)**

## 功能

- 繁體中文、手機與電腦皆可使用，Enter 直接配對。
- 相同姓名組合固定分數，交換順序不影響分數。
- 顯示娛樂用筆畫值、五行關係與拆字明細；未知字標記 `*`，以碼位穩定估算，不冒充真實筆畫。
- 範例、重設、複製結果；姓名不儲存、不傳送，沒有分析追蹤或第三方依賴。
- 姓名安全轉義，避免輸入被當成 HTML 執行。

## 執行與部署

直接用瀏覽器開啟 `index.html` 即可。GitHub Pages 設定為從 `main` 分支根目錄部署。

## 演算法

以初稿的有限筆畫表、總值差、五行關係、首字差、共同字與姓名雜湊組合計分，再限制在 1–100 分。空白會移除，字元以 NFKC 正規化。筆畫表未逐字校訂，結果純為娛樂，不是命理或關係建議。姓名先排序再產生種子，五行相生雙向同分。
